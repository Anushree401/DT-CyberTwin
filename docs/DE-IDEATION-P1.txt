  "edges": [
    {"from": "user_pc", "to": "server_a", "protocol": "ssh"},

  ]
}
sources:
manually defined (MVP)
network scans (later)
cloud configs (future)

{
  "user_pc": {

    "privilege": "user",
    "latency": 50
  }
}
Control state:
{
  "sensor_1": {
    "value": 40,

    "delay": 0
  }
}

  ]

{
